## 개발자 버전

### PWA 업데이트 자동화 + Android 뒤로가기 가드 적용

**index.html**
- Early `<script>`(동기)에서 `history.replaceState({__guard:true})` 실행 — 모듈 로딩 전 guard 상태 확보
- SW 등록: `updateViaCache:'none'` 옵션 추가, 기존 unregister/cache-clear 루프 제거
- `controllerchange` 이벤트 → `location.reload()` 자동 새로고침
- `visibilitychange` / `focus` 이벤트 → `reg.update()` 호출
- `version.txt` 30초 폴링 (`cache:'no-store'`), 버전 변경 감지 시 reload
- `style.css?v=1` 쿼리 파라미터 캐시 버스팅

**sw.js**
- activate에서 `client.navigate()` 제거 → controllerchange 방식으로 대체
- `SKIP_WAITING` message 리스너 추가
- CACHE_NAME `hanger-v43` → `hanger-v44`

**app.js**
- `popstate` 핸들러: `e.state.view` 없을 시 guard 도달로 판단 → `history.go(1)` 복구 + toast
- 2초 이내 재입력 시 종료 허용 (`_lastBackMs` 타임스탬프 비교)

**version.txt**
- 신규 생성 (초기값 `1`) — 배포 시 값 변경으로 자동 새로고침 트리거

**1. 앱 업데이트 자동화**
- 배포 후 사용자가 수동으로 새로고침 안 해도 됨
- 30초마다 새 버전 확인 → 있으면 자동으로 앱 새로고침
- 앱을 다시 켤 때도 업데이트 체크

**2. Android 뒤로가기 개선**
- 앱 화면에서 뒤로가기 눌러도 앱이 바로 꺼지지 않음
- "한 번 더 누르면 앱이 종료됩니다" 안내 메시지 표시
- 2초 안에 한 번 더 누르면 종료
