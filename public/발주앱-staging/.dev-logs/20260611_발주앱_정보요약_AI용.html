1. 앱이 하는 일

발주자(납품처)들이 현장에서 부족한 자재를 본사에 발주 요청 → 관리자가 확인 → 출고 처리. 그 과정에서 재고 자동 차감 + 이카운트 ERP 자동 연동(판매전표 생성)을 함.

주요 화면

  • 대시보드 — 오늘 발주, 부족 품목, 시흥/평택 재고 현황
  • 발주서 목록 — 발주 진행중/취소/보관 분리, 필터·검색
  • 발주서 등록/수정 모달 — 상부자재·서랍·선반 등 입력
  • 발주서 상세 — 인쇄·PDF·엑셀·이미지 저장, 상태 변경
  • 재고 관리 — 품목별 시흥/평택 재고, 색상별 분리
  • 품목 마스터 — 가구 품목 + 이카운트 코드 매핑
  • 발주 필요 목록 — 재고 부족 자동 집계
  • 사용량 통계 — 기간별 사용량 집계
  • 단가 관리 — 품목별 단가 설정
  • 계정 관리 — 관리자/발주자 계정

3. 발주서 상태 흐름

임시저장 → 발주대기 → 발주확정 → 출고준비 → 출고완료
                ↓         ↓
              취소     취소 (재고 롤백)
              보관     보관

상태별 의미

상태의미
임시저장발주자가 작성 중. 재고 미차감
발주대기발주자가 제출. 관리자 확정 대기. 재고 차감됨
발주확정관리자 확정. 이카운트 판매전표 자동 생성
출고준비물품 준비 중
출고완료출고 완료. 정산 대상
취소취소됨. 재고 자동 롤백
보관장기 보관 (취소는 아님)

7. 정산(Settlement)이 필요한 정보

이카운트 대체용 정산 페이지가 가져야 할 기능을 정리합니다. 발주앱 데이터로 다음을 집계 가능:

주요 집계 차원

  • 기간별: 일/주/월/연 단위
  • 납품처별 (납품처별)
  • 창고별 (시흥/평택)
  • 품목별
  • 카테고리별 (상부자재/서랍장/선반 등)
  • 색상별
  • 관리자별 (출고확정자)

주요 집계 항목

  • 발주 건수 / 출고 완료 건수
  • 공급가액 / 부가세 / 합계 금액
  • 품목별 출고 수량
  • 재고 차감/롤백 이력
  • 취소율

정산 행(row)에 반드시 표시할 항목

필드설명
orderNum (발주번호)식별자. 클릭 시 발주서 상세로 이동
orderDate (발주일)발주 접수 날짜
shipDate (출고일)출고 완료 날짜 (정산 기준일 후보)

warehouse (창고)시흥 / 평택
status (상태)출고완료 / 발주확정 등
totalAmount (합계)공급가 + 부가세
ecountSlipNos (이카운트 전표)이카운트 연동 시 발급된 전표 번호 (있는 경우)

정산 단계별 의미 (예시)

대상정산 기준
납품처별 정산출고완료된 발주서 합계 (월 단위)
VAT 신고월별 공급가액 / 부가세 합계
재고 회계월말 시흥/평택 재고 가액
매출 분석카테고리별·색상별·기간별

8. 기술적 제약

  • Firestore 컬렉션: hanger_orders (발주서 단건 문서) + hanger_data (계정·품목·재고·로그 등)
  • 발주서 doc ID = orderNum (YYYYMMDD-001 형태)
  • 인증: Firebase Auth (이메일/비밀번호)
  • Cloud Functions: Node.js 20, asia-northeast3 (서울)
  • 실시간 동기화: Firestore onSnapshot
  • 일일 백업: 매일 KST 자정에 _backups/{YYYY-MM-DD}
  • 현재 발주서 약 225건 (2026-06-11 기준), 추후 증가 예상

9. 비즈니스 규칙 (주요)

  • 재고는 발주대기 시 자동 차감, 취소 시 자동 롤백
  • 같은 발주서 동시 수정 차단 (inflight 가드)
  • 발주서 수정 시 재고 자동 롤백 후 재계산
  • 관리자만 출고확정 가능 (이카운트 전송 트리거)
  • 발주자는 자기 발주서만 수정 가능, 관리자는 전체 수정 가능
  • 발주확정된 발주서는 관리자가 확정 해제 후에만 수정 가능
  • 발주서별 단가는 단가 관리 페이지에서 설정 가능 (기본 단가표 fallback)

10. 정산 페이지 설계 시 고려사항

AI에게 정산 페이지를 기획시킬 때 알려줄 핵심:
  • 발주서는 한 건당 여러 카테고리(상부자재/서랍/선반 등) 품목을 포함하므로, "발주서별 → 품목별 펼침" UX 필요
  • 색상별 단가가 다르지 않지만 색상별 재고는 분리 → 재고 정산은 색상 차원도 필요
  • 출고완료된 발주서만 정산 대상 (취소·임시저장 제외)
  • 월별 정산 시 발주일 기준 vs 출고완료일 기준 구분 가능해야 함
  • 이카운트가 이미 발급한 판매전표 번호(ecountSlipNos)도 참조 가능
  • 현재 발주앱은 정산 페이지 없음. 새로 추가하는 것이 목표
