발주앱 ↔ 이카운트 ERP 연동 안정화

작성일
2026-06-10
대상
발주앱 (Firebase + 이카운트 ERP)

1. 문제

발주서 출고확정 시 이카운트로 판매전표가 자동 생성되지 않음.

원인: Firebase Cloud Function의 IP가 호출마다 바뀌어서 이카운트 IP 화이트리스트에 차단됨.

2. 임시 운영 방식

정식 인프라(Railway 등) 이전 전까지는 IP가 바뀔 때마다 즉시 알림받아 등록하는 방식으로 운영.

3. 동작 방식

  1. Cloud Function이 10분마다 현재 IP 확인
  2. 이전과 다르면 슬랙 + 발주앱 관리자에 알림
  3. 관리자가 새 IP를 이카운트 ERP에 추가 등록

4. 비용

모든 구성요소가 Firebase 무료 한도 내 + 슬랙 무료 → 월 0원
