# 트러블슈팅 로그 — 2026-04-24

## 회원가입 / 로그인

### 문제 1: 툭탁 이메일로 발주앱 회원가입 불가
- **원인**: 툭탁과 발주앱이 같은 Firebase 프로젝트를 공유 → 동일 이메일로 Auth 계정 중복 생성 불가
- **해결**: `auth/email-already-in-use` 오류 시 Firebase Auth 생성 건너뛰고 accounts에만 추가

### 문제 2: 이메일로 로그인 불가
- **원인**: 로그인 창이 아이디 입력만 지원
- **해결**: 입력값에 `@` 포함 시 이메일로 인식, accounts에서 이메일로 검색 → 없으면 Firebase Auth 인증 후 자동 계정 생성 (role: orderer)

---

## 계정 관련

### 문제 3: 관리자가 계정 이름 수정해도 납품처 이름 미반영
- **원인**: `submitAccount`에서 `name`만 업데이트하고 `deliveryName` 누락
- **해결**: orderer 계정 수정 시 `deliveryName`도 같이 업데이트
